# P6 可控姿态深度检查（2026-10-31）

使用同一 room1 manifest、seed=42 和相机配置，扫描七种姿态。每种姿态均
对照机器人/Gaussian/组合渲染，固定姿态重复两次，raw depth 逐像素一致。

```bash
uv run tests/run_g1_depth_diagnostics.py --pose-sweep \
  --output /tmp/p6-depth-pose-sweep
```

扫描姿态：reset；相对初始 root 左/右 yaw 90 度；局部 pitch 正/负 15 度；
左/右肩 pitch 设为 -pi/2（其余关节保持 reset）。这些是直接设置的运动学
配置，不是动力学推进轨迹，也不保证代表稳定行走姿态。

| 姿态 | 组合图缺失深度 | 正深度超出 5m | 机器人单独命中比例 | 组合相对 Gaussian-only 改变比例 |
|---|---:|---:|---:|---:|
| reset | 19.14% | 25.52% | 0% | 0% |
| 左转 90° | 23.27% | 35.16% | 0% | 0% |
| 右转 90° | 27.80% | 31.32% | 0% | 0% |
| 前俯 15° | 28.48% | 10.51% | 0% | 0% |
| 后仰 15° | 14.52% | 34.21% | 0% | 0% |
| 左臂抬起 | 18.26% | 20.31% | 19.14% | 19.14% |

所有图像没有非有限值，没有正深度 ≤0.05m。抬臂时最近深度约 0.133m，
属于真实机器人 mesh 遮挡，不应作为缺失值清除。机器人命中比例与组合
图改变比例吻合，说明这两种抬臂配置下自身几何进入视野。未出现自遮挡
的 reset/yaw/pitch 配置不能代替所有关节姿态的验证。

PNG 中白色可能代表缺失或有效深度超量程，不能用颜色判断深度有效性。

当前结论：相机姿态响应和有限配置的自遮挡链路符合预期，但 room1 覆盖率
仍有空洞。不要过滤所有近距离像素，也不要把缺失映射成 far 后宣称空间
已知。下一步需要真实 rollout 覆盖率、有效性通道的实验取舍、不同资产组
隔离及规模训练性能验证。

Gaussian-only 仍使用非空 BVH 占位方案，没有修复底层空 BVH 原生退出。
`make check` 与 Sphinx 文档构建通过。
