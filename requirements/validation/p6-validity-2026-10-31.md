# P6 独立 validity 通道评估（2026-10-31）

结论：双通道已实现并通过语义、真实相机、CNN/PPO 和 checkpoint 验证。
原单通道基线保留。当前证据证明 unknown/有效远端可以区分，不证明任务
收益，不替代多种子长训练和视觉消融。

## 通道定义与任务边界

| 任务后缀 | camera 形状 | channel 顺序 | experiment name |
|---|---|---|---|
| `3DGS-Depth` | `(B,1,48,64)` | depth | `g1_velocity_3dgs_depth` |
| `3DGS-Depth-Validity` | `(B,2,48,64)` | depth, validity | `g1_velocity_3dgs_depth_validity` |

完整任务名前缀均为 `Mjlab-Velocity-Flat-Unitree-G1-`。深度仍使用 zero-as-far
后裁剪并除以 5 的既有编码。validity 在裁剪前从原始深度计算：

```text
validity = float(isfinite(raw_depth) and raw_depth > 0)
```

| raw depth | depth 通道 | validity | 含义 |
|---|---:|---:|---|
| 0 | 1 | 0 | 缺失，不能证明自由空间 |
| 8m | 1 | 1 | 有限正深度，但超出 5m observation cutoff |
| 2m | 0.4 | 1 | 量程内有效渲染深度 |
| 0.02m | 0.01 | 1 | 近端裁剪，仍保留原始可用性 |
| NaN | NaN | 0 | depth 仍触发 observation error，不被 mask 掩盖 |

负数和 infinity 的 mask 也为零。validity 是 renderer 输出可用性的编码，
不是几何真值、置信度、接触可通行性或自由空间标签。它不补全缺失几何，
也不区分无 Gaussian 命中与累积 opacity 不足。

实现为 `camera_depth_validity` observation term。group 按 channel 维拼接，
两通道沿用同一 CameraSensor 缓存，不增加第二次渲染。动作、本体 observation、
奖励、相机配置及 PPO 超参数保持一致。两个模型的 actor/critic 均读取
camera；第一层卷积自动接收一个或两个输入通道。

## 相同预算的实现对照

```bash
uv run --locked tests/run_g1_3dgs_vision_smoke.py \
  --num-envs 2 --iterations 4 --depth-metrics \
  --scene-manifest src/mjlab/asset_zoo/3dgs/room1/manifest.json \
  --output /tmp/p6-validity-baseline

uv run --locked tests/run_g1_3dgs_vision_smoke.py \
  --validity-mask --num-envs 2 --iterations 4 --depth-metrics \
  --scene-manifest src/mjlab/asset_zoo/3dgs/room1/manifest.json \
  --output /tmp/p6-validity-paired
```

seed=42，每组四次 24-step PPO 更新，checkpoint 重载后再一次 24-step 更新，
每组共 240 个环境帧。两组初始 depth 数组逐像素完全相同；初始 mask 与
原始 finite-positive 深度在运行时测试中核对，覆盖 reset 后与 step 后。

| 检查 | 单通道 | depth + validity |
|---|---:|---:|
| actor 参数数 | 257018 | 257418 |
| CNN/PPO 短更新 | 通过 | 通过 |
| actor/critic/optimizer 重载与继续更新 | 通过 | 通过 |
| 双环境 partial reset 隔离 | 通过 | 通过 |

新增通道使每个 encoder 的第一层增加 400 个参数，actor/critic 各自有一个
encoder。仅翻转 mask、保持 depth 不变时，双通道 actor 的最大动作差约
0.00538，说明 mask 已被网络接入；不是学到了可靠利用 mask 的证明。

初始图像平均 24.02% 像素为 missing、28.17% 为有效远端。单通道中两者
均为 1，而双通道中分别为 `(1,0)`、`(1,1)`，消除了表示层的这项歧义。

## checkpoint 与后续实验

编码在运行报告及 checkpoint infos 中分别记录为 `depth-zero-as-far-v1` 和
`depth+finite-positive-validity-v1`，同时保存 task 和通道数并在重载时核对。
首层卷积权重分别为 `(16,1,5,5)` 与
`(16,2,5,5)`；测试确认两个方向 strict load 都报 shape mismatch。
不要用 `strict=False` 掩盖错误，当前不提供自动权重迁移。

下一步在视觉任务上以多个 seed、相同环境与训练预算比较单/双通道成功率、
回报和稳定性，并做 mask-only 干预及相机冻结等消融。room1 平地的短训练
不能证明视觉收益，更不能替代 P7 台阶任务。mask 是工程观测设计，不将
其作为 PPO、Spatial Softmax 或 3DGS 原始论文提出的新算法。

真实深度、mask 边界、通道拼接、基线隔离、严格 checkpoint 不兼容及
相机回归已纳入测试，本轮定向回归 `29 passed`；具体检查结果同步在项目 TODO。
最终 `make check` 和 `make docs` 均通过。
